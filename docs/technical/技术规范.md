## 3. 架构模式

### 3.1 分层架构
```
UI 层 (PySide6 Widgets)
    ↕ 信号/槽
引擎层 (QThread 异步执行)
    ↕
数据层 (SQLite via DBManager)
```

### 3.2 关键设计决策

- **数据库**：使用标准库 sqlite3，通过 DBManager 封装 CRUD，不引入 ORM（减少依赖）
- **异步执行**：测试执行使用 QThread，通过 Signal 将日志和结果推回 UI 线程
- **动态测试生成**：将用例配置动态拼接为 pytest 测试函数代码字符串，使用 subprocess 执行或写入 .py 文件导出
- **报告**：执行完毕后调用 ReportGenerator 读取结果数据库记录，使用 Python 字符串模板（非外部文件依赖）生成 HTML

## 4. 数据库设计

### 4.1 核心表

| 表 | 说明 | 关键字段 |
|----|------|----------|
| environments | 环境配置 | id, name, base_url |
| api_test_cases | 接口用例 | id, name, url, method, body_type, auth_type |
| api_headers | 请求头 | case_id(FK), key, value, enabled |
| api_assertions | 断言条件 | case_id(FK), assertion_type, target, operator, expected_value |
| web_test_cases | Web 用例 | id, name, browser, headless, start_url |
| web_steps | 操作步骤 | case_id(FK), step_order, action_type, input_value, enabled |
| web_step_locators | 元素定位 | step_id(FK), locator_type, locator_value |
| global_variables | 全局变量 | name, value, environment_id(FK) |
| test_results | 执行结果 | test_type, case_id, case_name, status, duration_ms |
| test_result_details | 结果详情 | result_id(FK), step_description, status, message, request/response |
| screenshots | 截图存储 | result_detail_id(FK), image_base64 |

### 4.2 数据关系
```
environments (1) ── (N) api_test_cases
environments (1) ── (N) web_test_cases
environments (1) ── (N) global_variables

api_test_cases (1) ── (N) api_headers
api_test_cases (1) ── (N) api_assertions

web_test_cases (1) ── (N) web_steps
web_steps (1) ── (N) web_step_locators

test_results (1) ── (N) test_result_details
test_result_details (1) ── (N) screenshots
```

## 5. 代码规范

- Python 3.10+ 语法，使用 f-string 和 type hints
- 遵循 PEP 8
- 类名 PacalCase，函数 snake_case
- UI 组件使用 PySide6 原生信号/槽机制
- 数据库操作统一通过 DBManager 静态方法
- 文件编码 UTF-8
