# 接口自动化测试工具 — 简历项目描述

---

## 项目名称

**接口自动化测试工具（API & Web Automated Testing Platform）**

## 项目概述

独立设计并开发的一款 Windows 桌面自动化测试平台，面向软件测试人员，集成**接口自动化测试**（基于 pytest + requests）和 **Web UI 自动化测试**（基于 Selenium WebDriver）两大核心引擎。支持测试用例管理、多环境配置、步骤编排、断言验证、测试报告生成等完整测试生命周期功能。

## 技术栈

| 层级 | 技术 | 
|------|------|
| 桌面框架 | PySide6（Qt for Python） |
| 接口测试引擎 | pytest + requests + jsonpath-ng |
| Web 测试引擎 | Selenium WebDriver + Chrome/Edge |
| 数据库 | SQLite（10 张业务表，外键约束，WAL 模式） |
| 报告系统 | Jinja2 HTML 模板 + Chrome CDP PDF 导出 |
| 浏览器管理 | webdriver-manager 自动驱动匹配 |
| 打包分发 | PyInstaller 单文件 .exe |
| 架构模式 | MVC 分层 + QThread 多线程异步执行 |

## 核心职责与成果

### 1. 系统架构设计
- 从零设计了完整的 MVC 分层架构：**UI 层**（PySide6 组件 + QSS 样式系统）、**引擎层**（QThread 异步执行线程）、**数据层**（SQLite + DBManager ORM 封装）
- 设计了 10 张数据库表的 ER 模型，包含环境管理、接口用例、Web 步骤编排、断言条件、执行结果、截图存储等完整业务实体
- 实现 QStackedWidget 多页面路由 + Signal/Slot 跨线程通信机制

### 2. 接口自动化测试引擎
- 开发了**进程内 HTTP 请求执行引擎**，直接使用 requests 库发起 GET/POST/PUT/DELETE/PATCH 等请求
- 支持 4 种认证方式（Bearer Token / Basic Auth / API Key / 无认证）
- 支持 4 种请求体格式（JSON / Form-Data / XML / Raw）
- 实现 JSONPath 响应体断言、状态码断言、响应时间断言三类验证逻辑
- 支持 `${变量名}` 占位符全局变量解析和多环境 Base URL 动态拼接
- **逐条用例独立判定 pass/fail/error**，断言结果记录期望值 vs 实际值

### 3. Web UI 自动化测试引擎
- 基于 Selenium WebDriver 实现**15 种操作类型**的步骤编排执行器
- 支持 8 种元素定位方式（ID/Name/Class/Tag/CSS/XPath/Link/Partial Link）
- 实现 Chrome/Edge 双浏览器支持，调试模式/无头模式双模式切换
- 开发**失败自动截图 + 手动截图步骤**机制，截图 Base64 嵌入 HTML 报告
- 支持步骤间变量提取与传递（`${变量名}` 引用）
- 实现步骤编辑器的拖拽排序、启用/禁用、插入/删除功能

### 4. 测试报告系统
- 独立开发 HTML 报告生成器，包含**概览看板、环境信息、用例详情、失败详情、执行日志**五大模块
- 失败用例展示完整请求/响应数据：URL、Method、Request Headers、RequestBody、ResponseStatus、ResponseBody
- 断言结果渲染期望值 vs 实际值对比（黄色卡片样式）
- 实现 Chrome DevTools Protocol（CDP）PDF 导出功能

### 5. 桌面客户端开发
- 使用 PySide6 开发完整桌面 GUI，包含首页导航、接口测试、Web 测试、报告查看、系统设置 5 个功能页面
- 设计蓝色主题 QSS 样式系统（600+ 行），覆盖按钮/表格/输入框/选项卡/滚动条/菜单等 30+ 组件
- 实现环境管理 CRUD、全局变量管理、浏览器驱动自动检测与手动配置
- 开发 pytest 脚本导出功能，生成独立 .py 测试文件供外部执行

### 6. 工程质量
- 编写 **95 项自动化验证用例**（覆盖数据库 CRUD、引擎逻辑、脚本生成、报告渲染、UI 组件初始化）
- 实现数据库 WAL 模式 + 连接超时 + 异常回滚，解决并发锁库问题
- 识别并修复 20+ 个缺陷（包括 URL 拼接错误、断言数据丢失、QSS Qt6 兼容性等）
- 配置 PyInstaller 打包脚本，支持一键构建独立 .exe

## 项目亮点

- **双引擎架构**：接口测试和 Web 测试共享统一的数据模型、报告系统和环境管理
- **逐条独立判定**：每条测试用例独立执行、独立断言、独立记录，而非批量 exit-code 判断
- **完整响应数据捕获**：请求/响应全量数据写入数据库，报告中可追溯每一步的详细信息
- **多线程异步执行**：QThread 后台执行不阻塞 UI，Signal 实时推送日志和响应数据到界面
- **企业级样式系统**：QSS 主题分离，组件样式统一管理，支持快速切换主题

## 项目规模

- 代码量：约 3500+ 行 Python（含 UI / 引擎 / 工具层）
- 数据库表：10 张，完整外键关联
- 测试用例：95 项自动化验证，通过率 100%
- 支持操作类型：接口 7 种 HTTP 方法 + Web 15 种操作类型
- UI 页面：5 个功能页面 + 4 个弹窗组件
