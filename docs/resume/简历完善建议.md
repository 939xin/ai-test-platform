## 二、如果时间允许，建议加的硬核功能（对简历加成最大）

### 🔥 P0: 命令行动态模式（+90% 简历效果）
```
python main.py --mode cli --cases login,register --env test
```
加一个 CLI 模式，支持无GUI执行。这样：
- 简历写"支持 CLI 模式，可集成 Jenkins/CI 流水线"
- 面试官最吃这套——"能和 CI 集成"
- 工作量：2-3 小时（解析参数 + 复用 engine 代码）

### 🔥 P1: 数据驱动
```
用例配置时选"数据源"→ 选 CSV/Excel → 每行数据跑一遍
```
接口测试界面的"数据驱动"标签：
- 上传 CSV → 每行参数作为一组数据 → 同一断言跑 N 次
- 简历写"支持数据驱动测试，CSV/Excel 参数化"
- 工作量：3-4 小时

### 🔥 P1: 用例导入导出（JSON）
```
[导出] → 选中用例 → 导出为 JSON → 发给同事
[导入] → 拖入 JSON → 自动创建用例
```
- 简历写"支持用例 JSON 导入导出，便于团队协作"
- 工作量：2 小时

### 🔥 P2: 执行历史趋势图
在报告页面加一个简单的通过率趋势折线图（用 matplotlib 生成图片）
- 简历写"测试结果趋势分析"
- 工作量：2 小时
