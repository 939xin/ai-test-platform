## 项目经验

**接口自动化测试工具** | 独立开发 | 2026.06

基于 PySide6 + pytest + Selenium 的 Windows 桌面自动化测试平台，集成接口测试和 Web UI 测试两大引擎，支持测试用例管理、步骤编排、断言验证、HTML 报告生成。

- 技术栈：PySide6、pytest、requests、Selenium、SQLite、Jinja2、PyInstaller
- 代码量 3500+ 行，10 张数据表，95 项自动化验证，通过率 100%

**核心贡献：**

1. 设计 MVC 分层架构，QStackedWidget 多页面路由 + QThread 多线程异步执行，UI 不阻塞
2. 开发接口测试引擎：支持 7 种 HTTP 方法、4 种认证、4 种 Body 格式，JSONPath/状态码/响应时间三类断言，逐条独立判定 pass/fail/error
3. 开发 Web 测试引擎：15 种操作类型、8 种定位方式、Chrome/Edge 双浏览器、失败自动截图嵌入报告
4. 自研 HTML 报告生成器：概览看板、请求/响应完整追溯、断言期望值 vs 实际值对比、Chrome CDP PDF 导出
5. 实现 QSS 主题样式系统（600+ 行），覆盖 30+ 组件，斑马纹表格、原生勾选框
6. 编写 95 项自动化验证用例，识别并修复 20+ 缺陷
