# UI 设计规范

> 项目：接口自动化测试工具  
> 版本：v1.0.0  

---

## 1. 配色方案

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色 | `#1976D2` | 导航栏、主要按钮、选中态 |
| 辅色 | `#1565C0` | 悬停态 |
| 深色 | `#0D47A1` | 按下态 |
| 背景 | `#f5f7fa` | 页面背景 |
| 卡片 | `#ffffff` | 卡片、表格背景 |
| 边框 | `#e0e0e0` | 常规边框 |
| 文字主色 | `#212121` | 主要文字 |
| 文字辅色 | `#616161` | 次要文字 |
| 成功 | `#388e3c` | 通过状态 |
| 危险 | `#d32f2f` | 失败/删除 |
| 警告 | `#ff9800` | 警告状态 |

## 2. 组件规范

### 2.1 按钮
- 主按钮：蓝色背景白色文字，圆角 6px，最小高度 32px
- 次按钮：白底蓝色边框蓝色文字
- 危险按钮：红色背景
- 成功按钮：绿色背景

### 2.2 表格
- 表头：浅灰背景，蓝色底部边框 2px
- 行：白色背景，hover 浅蓝
- 选中行：浅蓝背景 `#e3f2fd`
- 单元格内边距 6-8px

### 2.3 输入框
- 边框 1px `#bdbdbd`，圆角 4px
- Focus 态：蓝色边框 2px
- Disabled 态：灰色背景

### 2.4 卡片
- 白色背景，边框 `#e0e0e0`，圆角 8-12px

## 3. 页面布局

- 顶部导航栏：56px 高度，蓝色背景，水平排列按钮 + Logo
- 内容区域：自适应填充剩余空间
- 状态栏：底部，显示当前状态

## 4. 字体

- 统一使用 Microsoft YaHei（微软雅黑）
- 大小：标题 22px/14px，正文 13px，辅助 12px/11px
