# 开发流程与规范

> 项目：接口自动化测试工具  
> 版本：v1.0.0  

---

## 1. 开发阶段总览

| 阶段 | 内容 | 状态 |
|------|------|------|
| Phase 1 | 基础框架搭建（项目结构、数据库、主窗口、首页） | 🟡 进行中 |
| Phase 2 | 接口自动化测试（环境管理、用例编辑、执行引擎、脚本导出） | ⬜ 待开始 |
| Phase 3 | Web 自动化测试（步骤编排、执行引擎、浏览器管理） | ⬜ 待开始 |
| Phase 4 | 测试报告（HTML 报告生成、报告查看器、PDF 导出） | ⬜ 待开始 |
| Phase 5 | 收尾与打包（设置页、结果历史、PyInstaller 打包） | ⬜ 待开始 |

## 2. 每日开发流程

1. 查看 `dev_logs/` 最新日志，了解当前进度
2. 查看 `time/` 确认当前版本目标
3. 开发功能模块
4. 每完成一个模块，运行验证脚本确保无回归
5. 每日结束时，更新开发日志

## 3. 代码提交规范

- 每完成一个独立功能点写一条日志
- 提交前确保应用能正常启动
- 重大变更在 `time/` 中记录

## 4. 验证方式

| 阶段 | 验证内容 |
|------|----------|
| Phase 1 | 启动应用 → 首页入口卡片可见 → 点击可跳转页面 |
| Phase 2 | 创建接口用例 → 填写配置 → 执行 → 查看结果 → 导出脚本 |
| Phase 3 | 创建 Web 用例 → 编排步骤 → 调试模式执行 → 无头模式执行 |
| Phase 4 | 执行后自动生成 HTML 报告 → 报告中含截图 |
| Phase 5 | PyInstaller 打包后在其他机器上解压即用 |

## 5. 项目启动命令

```bash
# 创建虚拟环境
python -m venv venv
source venv/Scripts/activate

# 安装依赖
pip install -r requirements.txt

# 运行应用
python main.py

# 打包
pyinstaller --onefile --windowed --name "接口自动化测试工具" main.py
```
