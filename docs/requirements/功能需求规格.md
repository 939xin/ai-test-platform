# 功能需求规格说明书

> 项目：接口自动化测试工具  
> 版本：v1.0.0  
> 更新日期：2026-06-27

---

## 1. 项目概述

构建一个 Windows 桌面自动化测试工具，面向测试人员，覆盖两大核心场景：
- **接口自动化测试**：基于 pytest + requests，通过配置 URL/参数/断言完成接口测试
- **Web 自动化测试**：基于 Selenium，通过步骤列表编排完成浏览器操作测试

## 2. 功能需求

### 2.1 首页导航
- 两个功能入口卡片：接口自动化测试 / Web 自动化测试
- 点击卡片跳转对应功能页面
- 显示版本号和快速特性概览

### 2.2 接口自动化测试

#### 2.2.1 用例配置
| 配置项 | 说明 |
|--------|------|
| 用例名称 | 必填，唯一标识 |
| 请求 URL | 支持 `${变量}` 占位符，支持相对路径（拼接环境 Base URL） |
| 请求方法 | GET / POST / PUT / DELETE / PATCH / HEAD / OPTIONS |
| 请求头 | 键值对列表，支持增删、启用/禁用 |
| 请求体 | JSON / Form-Data / XML / Raw，JSON 模式下支持格式化 |
| 认证方式 | 无认证 / Bearer Token / Basic Auth / API Key |
| 超时时间 | 可配置（默认 30 秒） |
| 断言条件 | 状态码（等于/不等于）、响应体 JSONPath（等于/包含/正则）、响应时间（小于 N ms） |

#### 2.2.2 环境管理
- 支持多环境：开发/测试/预发布/生产
- 每环境配置独立 Base URL
- 用例 URL 支持 Base URL + 路径拼接

#### 2.2.3 执行与结果
- 界面内实时执行 + 展示结果
- 动态生成 pytest 测试函数并运行
- 执行日志实时输出
- 导出独立 .py pytest 脚本

### 2.3 Web 自动化测试

#### 2.3.1 步骤编排器
- 表格形式，每行一个操作步骤
- 列：序号、启用、操作类型、定位方式、定位值、输入值、等待时间、描述
- 支持上移/下移排序
- 支持插入/删除/启用/禁用

#### 2.3.2 操作类型（15 种）
| 类型 | 参数 |
|------|------|
| 打开 URL | URL 地址 |
| 点击元素 | 定位方式 + 定位值 |
| 输入文本 | 定位 + 文本内容 |
| 清空输入 | 定位 |
| 强制等待 | 秒数 |
| 智能等待 | 定位 + 超时时间 |
| 窗口切换 | 窗口索引/title |
| IFrame 切换 | iframe 定位或 default |
| 滚动到元素 | 定位 |
| 执行 JS | JS 代码 |
| 截图 | 截图名称 |
| 断言-文本包含 | 定位 + 期望文本 |
| 断言-元素可见 | 定位 + true/false |
| 断言-元素存在 | 定位 + true/false |
| 提取变量 | 定位 + 变量名 |

#### 2.3.3 元素定位（8 种）
ID / Name / Class Name / Tag Name / CSS Selector / XPath / Link Text / Partial Link Text

#### 2.3.4 变量传递
- `${变量名}` 占位符，支持全局变量 + 运行时提取变量
- 步骤间可通过"提取变量"操作传递数据

#### 2.3.5 执行模式
- 调试模式（默认）：打开浏览器窗口，可见操作
- 无头模式：后台运行（可选勾选）

#### 2.3.6 浏览器支持
- Chrome（需 ChromeDriver）
- Edge（需 EdgeDriver）
- 驱动路径自动检测 + 手动配置

### 2.4 测试报告

#### 2.4.1 HTML 报告五模块
1. 概览看板：总数/通过/失败/跳过/通过率/总耗时
2. 环境信息：时间/OS/Python版本/浏览器版本
3. 用例详情列表
4. 失败详情：接口（URL/Method/Req/Rsp/断言对比）Web（失败截图 Base64 嵌入）
5. 执行日志

#### 2.4.2 截图机制
- 失败自动截图：断言失败或异常时自动截取
- 手动截图步骤：步骤列表中"截图"操作类型
- 截图以 Base64 嵌入 HTML 报告，点击可放大

#### 2.4.3 PDF 导出
- 进阶功能，通过浏览器打印实现

## 3. 非功能需求

- UI：实用风格，蓝色主题（主色 #1976D2）
- 平台：Windows 10/11
- 数据库：SQLite，本地存储
- 语言：Python 3.10+
- 打包：PyInstaller 单文件 .exe
