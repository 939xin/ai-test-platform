## 第一步：环境准备

### 1.1 安装依赖
```bash
# 在项目目录下打开终端
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

或者直接运行：
```
scripts\setup.bat
```

### 1.2 启动应用
```bash
venv\Scripts\activate
python main.py
```

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| 启动报错 ImportError | 确认已 `pip install -r requirements.txt` |
| Selenium 驱动报错 | 确认已安装 Chrome/Edge 浏览器，或在设置页手动指定驱动路径 |
| Web 测试执行失败 | 先用无头模式测试；确保驱动版本与浏览器版本匹配 |
| 报告文件找不到 | 确认 `reports/` 目录有写入权限 |
